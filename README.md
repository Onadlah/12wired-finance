# 12WIRED Finance

Static web app for 12WIRED artist-hospitality expenses. Open https://onadlah.github.io/12wired-finance/ and connect Dropbox.

Each person signs in with their own 12WIRED Dropbox account and sees only the folders they are allowed to open. The app works only inside the FINANCE folder of an event folder in the team's PROJECTS folder, and only in folders whose access is restricted. This repository holds only the built app files: no data, passwords or secrets. The Dropbox app key in dropbox.js is a public client ID, not a secret.
